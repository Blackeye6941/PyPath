
# PyPath

A beautifully designed, self-paced learning application crafted to take you from writing your first line of Python to deploying production-ready AI/ML models. Featuring a soothing dark-mode interface, the app seamlessly bridges the gap between software engineering and data science using dynamic, LLM-powered curriculum generation.

---

## Learning Curriculum

The roadmap is strictly structured into four progressive modules, ensuring a friction-free transition from beginner to AI/ML Professional:

### 1. Python Fundamentals (12 Chapters)
* Core syntax, variables, data types, and operations.
* Control flow, loops, and conditional execution.
* Data structures: Lists, Dictionaries, Tuples, and Sets.
* Functions, scope, modular programming, and File I/O.

### 2. Advanced Python (8 Chapters)
* Object-Oriented Programming (OOP): Inheritance, Polymorphism, and Encapsulation.
* Dunder methods, custom iterators, and generators.
* Functional programming, closures, and decorators.
* Concurrency, multithreading, and asynchronous programming (`asyncio`).

### 3. FastAPI (8 Chapters)
* RESTful API design principles and routing.
* Request validation and parsing using Pydantic.
* Dependency injection, authentication, and middleware security.
* Database integration, ORMs, and containerized deployment.

### 4. AI/ML with Python (12 Chapters)
* Mathematical foundations & Data manipulation (NumPy, Pandas, Matplotlib).
* Classical Machine Learning with Scikit-learn (Regression, Tree-based models, Clustering).
* Deep Learning and Neural Network architectures using PyTorch.
* Modern AI: Large Language Models (LLMs), Prompt Engineering, and Retrieval-Augmented Generation (RAG).

---

## Key Features

* **Dynamic Content Generation:** Every single chapter is structurally compiled on-the-fly using the **Google Gemini API**, providing fresh explanations, real-world analogies, syntax-highlighted code blocks, and tailored concept cards.
* **PyMentor AI Chat:** A contextual, per-lesson chatbot companion. Ask for alternative explanations, request custom edge-case examples, or challenge yourself with impromptu pop quizzes.
* **Quick Quiz Tab:** Evaluate your comprehension instantly with AI-generated, topic-specific multiple-choice and conceptual questions.
* **Intelligent Hints Tab:** Stuck on a concept? Access a dedicated tab outlining debugging tips, architectural mental models, and common pitfalls associated with the current chapter.
* **Interactive Practice Area:** Features an embedded code editor paired with an **AI Challenge Generator** and a real-time **AI Code Reviewer** to analyze your code for efficiency, style, and bugs.
* **Local Progress Tracking:** Seamlessly mark chapters as complete and save your exact learning state directly in your browser. Pick up exactly where you left off.

---

## Design Philosophy

* **Calm & Focused:** A soothing, dark-themed UI designed with muted accents to eliminate eye strain during long, late-night coding sessions.
* **Distraction-Free UX:** Clean typography, generous spacing, and smooth transitions prioritize readability and hands-on experimentation.

## Getting Started & Local Setup

We welcome contributors! Follow these steps to clone the repository, set up your local environment, and spin up the development servers.

### Prerequisites
* Git installed on your system.
* Python 3.10+ installed.
* Node.js (v18 or higher) and `npm` installed.
* A **Google Gemini API Key** (Get one from Google AI Studio).

### 1. Clone the Repository
```
git clone https://github.com/Blackeye6941/PyPath.git
cd pyai-academy
```
