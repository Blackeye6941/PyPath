# PyPath — Python to AI/ML Mastery

PyPath is a structured, AI-powered learning platform designed to take you from Python basics to building production-ready AI and Machine Learning systems.

## 🚀 Features

- **AI-Generated Lessons:** Every chapter is dynamically generated by an AI tutor to be thorough and engaging.
- **Practice Exercises:** Every lesson ends with two practice questions and expected outputs to test your knowledge.
- **Interactive Quizzes:** Test your understanding with AI-generated quizzes for every chapter.
- **AI Tutor (PyMentor):** A dedicated AI assistant to answer your questions, provide hints, and review your code.
- **Practice Environment:** A built-in Python editor with an AI Code Assistant for free coding and challenges.

## 📚 Curriculum Structure

The curriculum is divided into 4 core modules, covering 40 chapters in total:

1.  **🐍 Python Fundamentals (12 Chapters):** Variables, Data Types, Control Flow, Loops, Functions, and Error Handling.
2.  **⚡ Advanced Python (8 Chapters):** OOP, Decorators, Generators, Async/Await, and Testing.
3.  **🚀 FastAPI (8 Chapters):** Building REST APIs, Authentication, Databases, and Deployment.
4.  **🧠 AI/ML with Python (12 Chapters):** NumPy, Pandas, Scikit-learn, PyTorch, Transformers, and LLMs.

## 🛠️ How to Use

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/your-username/PyPath.git
    ```
2.  **Open `index.html`:** Open the `index.html` file in any modern web browser.
3.  **Enter API Key:** You will need a free Groq API key to power the AI features.
    - Get a key at [console.groq.com](https://console.groq.com/keys).
    - Enter the key when prompted in the application.
4.  **Start Learning:** Select a module and chapter from the sidebar to begin your journey.

## 🤝 How to Contribute

We welcome contributions to improve PyPath! Here is how you can help:

-   **Improve AI Prompts:** Refine the logic in `script.js` (specifically the `llmLesson` function) to improve the quality of generated lessons.
-   **Enhance UI/UX:** Suggest or implement CSS improvements in `style.css`.
-   **Expand Curriculum:** Propose new modules or chapters in `script.js`.
-   **Bug Fixes:** Report or fix issues in the application logic.

### Steps to Contribute:
1.  Fork the repository.
2.  Create a new branch (`git checkout -b feature/improvement`).
3.  Commit your changes (`git commit -am 'Add some improvement'`).
4.  Push to the branch (`git push origin feature/improvement`).
5.  Create a new Pull Request.
